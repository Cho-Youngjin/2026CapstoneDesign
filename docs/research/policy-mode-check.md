## 배터리 (참고값, 실험 자료로 쓰지 않음)

- 세션 1: 전하량 118.6 mAh 감소 / 41.5분 → **시간당 약 171 mAh**. 세션 2: 약 161 mAh/h(5.5분이라 계단 4개, 거칠다).
- 정답 기록 모드(1초 GPS, 시간당 184 mAh, `device-check.md`)와 거의 같아 원인을 batterystats로 확인했다(두 세션 47분).
  - 이 앱의 GPS 사용 30분 44초, CPU 약 18분, 와이파이 스캔 321회
  - 다른 앱의 블루투스 스캔이 계속 돌았다(우리 앱과 무관한 바탕 소모)
- 다음 날 점검(`trip-check.md`)에서 **지도 화면의 실시간 경로가 앱이 백그라운드로 가도 GPS를 끄지 않는 버그**를 찾았다. 가만히 있으면 10m 거리 필터 때문에 새 위치가 오지 않아 몇 시간씩 켜져 있었다. 9be5d64에서 고쳤고 실기기로 확인했다.
- 이 두 세션의 배터리 값에는 그 버그가 섞였을 수 있어 배터리 실험(설계 8-2) 자료로 쓰지 않는다. 고친 빌드로 다시 잰다.

## 결론

- 정책 실행 모드는 **화면이 꺼진 상태에서 설계대로 동작한다**. 측위 시점, 상태 전환, 파일 구성, 깨우기 지연 모두 통과다.
- 배터리 실험 전에 할 것
  - 고친 빌드(9be5d64 이후)로 다시 설치한다.
  - 실험 조건에 **블루투스 끄기**를 더한다(다른 앱의 스캔이 바탕 소모를 키운다).
  - 결과에 '유심 없는 폰'을 조건으로 적는다.
